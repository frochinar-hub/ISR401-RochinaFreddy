# ISR401 - Ingeniería de Requisitos

Repositorio oficial para las actividades académicas y entregas prácticas de la asignatura **Ingeniería de Requisitos (ISR401)**, cursada en la Universidad Técnica Estatal de Quevedo (UTEQ).

---

## Estructura del Repositorio

El repositorio se encuentra organizado por carpetas correspondientes a cada entregable del periodo académico:

* **`TA-IND-01/`**: Carpeta de la actividad de análisis de requerimientos de **Microsoft Teams**, basada en las normativas internacionales **ISO/IEC/IEEE 29148:2018** e **ISO/IEC 25010:2023**.
  * `documento.tex`: Código fuente principal en LaTeX.
  * `documento.pdf`: Documento compilado formal de la tarea.
  * `referencias.bib`: Archivo BibTeX con las fuentes bibliográficas formato IEEE.
  * `figuras/`: Subcarpeta que contiene las evidencias visuales (capturas de pantalla de Equipos, Chat y Calendario).

---

## Tecnologías y Herramientas Utilizadas

* **Lenguaje de Documentación:** LaTeX (Overleaf / Compilación local).
* **Control de Versiones:** Git y GitHub.
* **Normativas de Referencia:** IEEE 29148:2018, ISO 25010:2023.
