# ISR401 - Taller de tipos de requisitos (FORM-TL-01)

Repositorio personal para la asignatura de Ingeniería de Requerimientos (ISR-401).

## Contenido del repositorio
- `documento.tex`: Código fuente en LaTeX del informe.
- `referencias.bib`: Archivo de bibliografía en formato BibTeX (estilo IEEE).
- `documento.pdf`: Documento compilado final.

## Instrucciones de compilación
Para regenerar el documento PDF a partir del código fuente:
1. Utilizar un compilador compatible con LaTeX (como pdfLaTeX o TeXstudio).
2. Compilar el archivo principal `documento.tex` ejecutando el motor LaTeX y BibTeX para procesar las referencias bibliográficas.
